# Multimodal AI - Demonstrations

Hands-on demonstrations of multimodal AI concepts.

## Included Demos

### Demo 1: CLIP Exploration
Use CLIP for zero-shot image classification and retrieval.
```bash
python demo/01_clip_exploration.py
```

### Demo 2: Image Generation
Generate images with Stable Diffusion and explore prompting.
```bash
python demo/02_image_generation.py
```

### Demo 3: Vision-Language Model
Query a VLM about images (using LLaVA or similar).
```bash
python demo/03_vlm_querying.py
```

### Demo 4: Multimodal RAG
Build a RAG system that retrieves both text and images.
```bash
python demo/04_multimodal_rag.py
```

### Demo 5: Audio Processing
Transcribe and analyze audio with Whisper.
```bash
python demo/05_audio_processing.py
```

### Demo 6: Diffusion Internals
Visualize the denoising process step by step.
```bash
python demo/06_diffusion_internals.py
```

## Requirements

- GPU recommended (especially for generation demos)
- ~16GB RAM for larger models
- Internet connection for model downloads
