# Fine-Tuning & Adaptation: Beyond the Basics

## Current Trends (2024-2026)

### 1. Mixture of Experts (MoE) Fine-tuning
Fine-tune specific experts for different tasks.

### 2. Merging & Model Soups
Combine multiple fine-tuned models.

### 3. Continued Pre-training
Domain-specific continued pre-training before SFT.

### 4. Synthetic Data
Use LLMs to generate training data.

## Emerging Methods

| Method | Status | Key Innovation |
|--------|--------|----------------|
| ORPO | Production | No reference model needed |
| SimPO | Research | Simplified preference optimization |
| KTO | Research | Works with binary feedback |
| DoRA | Research | Decomposed LoRA |
