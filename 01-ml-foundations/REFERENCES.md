# ML Foundations: Key References

A curated collection of foundational textbooks, papers, and resources for machine learning fundamentals.

---

## 📚 How to Use This Document

- **📖 Essential**: Core textbooks and papers everyone should read
- **🔧 Hands-on**: Resources with practical implementations
- **📝 Reference**: Materials for deeper exploration

---

## Foundational Textbooks

### Pattern Recognition and Machine Learning
**Christopher M. Bishop, 2006**

The definitive textbook for probabilistic approaches to machine learning.

- **Key topics**: Probability distributions, linear models, neural networks, kernel methods, graphical models
- **Best for**: Understanding the mathematical foundations
- **Link**: [Springer](https://www.springer.com/gp/book/9780387310732)
- **Status**: 📖 Essential

---

### Machine Learning: A Probabilistic Perspective
**Kevin P. Murphy, 2012**

Comprehensive coverage of machine learning from a probabilistic viewpoint.

- **Key topics**: Probability, statistics, optimization, supervised/unsupervised learning
- **Link**: [MIT Press](https://mitpress.mit.edu/9780262018029/machine-learning/)
- **Status**: 📖 Essential

---

### The Elements of Statistical Learning
**Hastie, Tibshirani, Friedman, 2009**

Statistical perspective on machine learning with rigorous mathematical treatment.

- **Key topics**: Supervised learning, model selection, ensemble methods
- **Link**: [Stanford (Free PDF)](https://hastie.su.domains/ElemStatLearn/)
- **Status**: 📖 Essential

---

### Deep Learning: Foundations and Concepts
**Christopher M. Bishop & Hugh Bishop, 2024**

Modern textbook bridging classical ML and deep learning.

- **Key topics**: Neural networks, transformers, generative models
- **Link**: [Springer](https://link.springer.com/book/10.1007/978-3-031-45468-4)
- **Status**: 📖 Essential

---

## Mathematics for ML

### Mathematics for Machine Learning
**Deisenroth, Faisal, Ong, 2020**

Purpose-built math textbook for ML practitioners.

- **Key topics**: Linear algebra, calculus, probability, optimization
- **Link**: [Cambridge (Free PDF)](https://mml-book.github.io/)
- **Status**: 🔧 Hands-on

---

### Convex Optimization
**Stephen Boyd & Lieven Vandenberghe, 2004**

The standard reference for optimization in machine learning.

- **Key topics**: Convex sets, convex functions, duality, algorithms
- **Link**: [Stanford (Free PDF)](https://web.stanford.edu/~boyd/cvxbook/)
- **Status**: 📖 Essential

---

### Linear Algebra Done Right
**Sheldon Axler, 2024 (4th Edition)**

Elegant approach to linear algebra focusing on vector spaces.

- **Link**: [Springer (Free)](https://linear.axler.net/)
- **Status**: 📝 Reference

---

## Seminal Papers

### Random Forests
**Leo Breiman, 2001**

Introduction of random forests, one of the most successful ML algorithms.

- **Key innovations**: Bootstrap aggregating with random feature selection
- **Link**: [Springer](https://link.springer.com/article/10.1023/A:1010933404324)
- **Status**: 📖 Essential

---

### Support Vector Networks
**Corinna Cortes & Vladimir Vapnik, 1995**

Original paper introducing Support Vector Machines.

- **Key innovations**: Maximum margin classifiers, kernel trick
- **Link**: [Springer](https://link.springer.com/article/10.1007/BF00994018)
- **Status**: 📖 Essential

---

### A Few Useful Things to Know About Machine Learning
**Pedro Domingos, 2012**

Practical wisdom about what matters in machine learning.

- **Link**: [ACM](https://dl.acm.org/doi/10.1145/2347736.2347755)
- **Status**: 📖 Essential
