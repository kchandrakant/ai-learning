# ML Foundations Demos

Interactive demonstrations for core ML concepts.

## Available Demos

### 1. Linear Algebra Visualizer (`linear_algebra_demo.py`)
Visualize vectors, matrices, and transformations.

```bash
python demo/linear_algebra_demo.py
```

### 2. Gradient Descent Animation (`gradient_descent_demo.py`)
Watch gradient descent minimize a loss function.

```bash
python demo/gradient_descent_demo.py
```

### 3. Linear Regression (`linear_regression_demo.py`)
Fit lines to data, visualize loss surface.

```bash
python demo/linear_regression_demo.py
```

### 4. Classification Boundaries (`classification_demo.py`)
Visualize decision boundaries for different classifiers.

```bash
python demo/classification_demo.py
```

### 5. Bias-Variance Tradeoff (`bias_variance_demo.py`)
See underfitting vs overfitting with polynomial regression.

```bash
python demo/bias_variance_demo.py
```

### 6. Regularization Effects (`regularization_demo.py`)
Compare L1 vs L2 regularization on coefficients.

```bash
python demo/regularization_demo.py
```

### 7. Tree Visualization (`tree_demo.py`)
Visualize decision tree splits.

```bash
python demo/tree_demo.py
```

### 8. Ensemble Comparison (`ensemble_demo.py`)
Compare Random Forest vs Gradient Boosting.

```bash
python demo/ensemble_demo.py
```

## Running Demos

```bash
pip install -r requirements.txt
python demo/<demo_name>.py
```

Each demo generates visualizations saved as PNG files.

---

Start with `gradient_descent_demo.py` to see optimization in action.
