# AI Security & Identity Demos

Interactive demonstrations of security concepts.

## Available Demos

### 1. API Key Security (`api_key_demo.py`)
Demonstrate secure key management patterns.

```bash
python demo/api_key_demo.py
```

### 2. OAuth Flows (`oauth_demo.py`)
Walk through different OAuth flows.

```bash
python demo/oauth_demo.py
```

### 3. Agent Identity (`identity_demo.py`)
Create and verify cryptographic agent identities.

```bash
python demo/identity_demo.py
```

### 4. Token Flow (`token_demo.py`)
Visualize complete token exchange.

```bash
python demo/token_demo.py
```

### 5. AAuth Protocol (`aauth_demo.py`)
Full AAuth authorization flow.

```bash
python demo/aauth_demo.py
```

### 6. Access Control (`access_control_demo.py`)
Compare RBAC, ABAC, and capability patterns.

```bash
python demo/access_control_demo.py
```

### 7. Prompt Injection (`injection_demo.py`)
Demonstrate injection attacks and defenses.

```bash
python demo/injection_demo.py
```

### 8. Audit Logging (`audit_demo.py`)
Generate and analyze audit trails.

```bash
python demo/audit_demo.py
```

## Running Demos

```bash
pip install -r requirements.txt
python demo/<demo_name>.py
```

## Recommended Order

1. `api_key_demo.py` - Start with basics
2. `oauth_demo.py` - Understand OAuth
3. `identity_demo.py` - Agent identity
4. `token_demo.py` - Token mechanics
5. `aauth_demo.py` - Full protocol
6. `access_control_demo.py` - Authorization models
7. `injection_demo.py` - Security threats
8. `audit_demo.py` - Monitoring

---

These demos provide hands-on experience with AI security concepts.
