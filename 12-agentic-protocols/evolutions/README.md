# Agentic Protocols Evolutions

## Emerging Standards

### AITP (AI Transfer Protocol)
HTTP-like protocol designed for AI agents.
- Request-response semantics
- Native streaming support
- Built-in capability negotiation

### Agent Protocol (agentprotocol.ai)
Universal agent communication standard.
- Language-agnostic
- Supports multiple transports
- Focus on interoperability

### Decentralized Identifiers (DIDs) for Agents
Blockchain-anchored agent identity.
- Self-sovereign identity
- Cross-platform verification
- Trust without centralization

## Protocol Extensions

### MCP Extensions
- **MCP Auth:** Authentication layer for MCP
- **MCP Streaming:** Enhanced streaming support
- **MCP Federation:** Cross-server discovery

### A2A Extensions
- **A2A Workflows:** Multi-step task coordination
- **A2A Marketplace:** Agent discovery marketplace
- **A2A Enterprise:** Enterprise security features
