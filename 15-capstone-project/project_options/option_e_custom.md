# Option E: Custom Project

Design and build your own AI application that demonstrates mastery of course concepts.

## Project Description

Create a project of your own design that applies the skills learned across the course. This option gives you complete creative freedom while ensuring you demonstrate core competencies.

## Requirements

### Proposal Requirements

Before starting, submit a proposal including:

1. **Problem Statement**: What problem are you solving?
2. **Target Users**: Who will use this?
3. **Core Features**: What will it do? (minimum 3)
4. **Technical Approach**: What models/techniques will you use?
5. **Evaluation Plan**: How will you measure success?
6. **Timeline**: 8-week schedule with milestones

### Technical Requirements

Your project MUST include at least 4 of the following:

- [ ] **RAG Pipeline**: Document retrieval and augmented generation
- [ ] **Local LLM**: Ollama or similar local deployment
- [ ] **Prompt Engineering**: Well-designed prompts with examples
- [ ] **Tool Integration**: External API or tool use
- [ ] **Agentic Behavior**: Planning, reasoning, or multi-step execution
- [ ] **Multimodal**: Image, audio, or video processing
- [ ] **Fine-tuning**: Custom model adaptation
- [ ] **Evaluation Framework**: Systematic quality measurement
- [ ] **Production Features**: Caching, logging, monitoring
- [ ] **API Design**: RESTful or GraphQL interface

### Quality Standards

- Clean, documented code
- Comprehensive error handling
- At least 5 test cases
- Docker deployment
- README with setup instructions

## Example Project Ideas

### Domain-Specific Applications

1. **Legal Contract Analyzer**: Extract clauses, compare contracts
2. **Recipe Assistant**: Ingredient-based search, substitutions, scaling
3. **Study Buddy**: Flashcard generation, quiz creation from notes
4. **Interview Prep Bot**: Mock interviews with feedback
5. **Meeting Summarizer**: Audio → transcript → action items

### Developer Tools

6. **Git Commit Assistant**: Generate meaningful commit messages
7. **Documentation Generator**: Code → documentation
8. **API Testing Assistant**: Generate test cases from OpenAPI specs
9. **Migration Helper**: Framework/version migration guidance

### Creative Applications

10. **Story Collaborator**: Interactive fiction with memory
11. **Character Chat**: Roleplay with consistent personas
12. **World Builder**: Consistent fictional world generation

### Specialized Agents

13. **Data Analysis Agent**: Natural language → SQL → visualization
14. **Shopping Assistant**: Product comparison with RAG
15. **Travel Planner**: Itinerary generation with constraints

## Evaluation Criteria

| Criterion | Weight | Description |
|-----------|--------|-------------|
| Innovation | 20% | Creative problem-solving |
| Technical Depth | 25% | Proper use of AI techniques |
| Completeness | 20% | All proposed features work |
| Code Quality | 15% | Clean, documented, tested |
| Presentation | 10% | Clear demo and documentation |
| Self-Assessment | 10% | Honest evaluation of results |

## Deliverables

1. **Proposal**: Approved project proposal
2. **Source Code**: Complete, documented application
3. **Design Document**: Architecture and decisions
4. **Demo Video**: 10-minute walkthrough
5. **Self-Evaluation**: Detailed assessment

## Tips for Success

1. **Start Small**: Build MVP first, then expand
2. **Validate Early**: Test assumptions before building
3. **Document As You Go**: Don't leave it to the end
4. **Ask for Feedback**: Get input at each milestone
5. **Scope Carefully**: Better to finish less than abandon more
