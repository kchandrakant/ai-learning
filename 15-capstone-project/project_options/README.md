# Capstone Project Options

Choose one of the following project options for your capstone. Each option includes a complete template with starter code and documentation.

## Overview

| Option | Difficulty | Primary Skills | Time Estimate |
|--------|------------|----------------|---------------|
| A. Domain Assistant | ⭐⭐⭐ | RAG, Prompt Engineering | 6-8 weeks |
| B. Code Assistant | ⭐⭐⭐⭐ | RAG, Code Analysis | 8-10 weeks |
| C. Research Agent | ⭐⭐⭐⭐⭐ | Agentic, Multi-source | 8-10 weeks |
| D. Multimodal Assistant | ⭐⭐⭐⭐ | Vision, Cross-modal | 8-10 weeks |
| E. Custom Project | Varies | Your choice | Varies |

## Quick Selection Guide

**Choose Domain Assistant if you want to:**
- Build a practical RAG application
- Focus on prompt engineering and retrieval
- Deploy something production-ready quickly

**Choose Code Assistant if you want to:**
- Work with code parsing and analysis
- Build developer tools
- Explore code-specific embeddings

**Choose Research Agent if you want to:**
- Implement agentic patterns (planning, tool use)
- Work with multiple data sources
- Build autonomous systems

**Choose Multimodal Assistant if you want to:**
- Work with vision models
- Combine text and image understanding
- Explore cross-modal retrieval

**Choose Custom Project if you want to:**
- Apply skills to your specific domain
- Work on a novel problem
- Have complete creative freedom
