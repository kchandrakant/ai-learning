# Multi-Agent Systems: Key References

A curated collection of papers on LLM-based multi-agent systems and orchestration.

- **📖 Essential**: Core papers everyone should read
- **🔧 Hands-on**: Papers with practical implementations
- **🔬 Frontier**: Cutting-edge research

## Foundational Agent Papers

### ReAct: Synergizing Reasoning and Acting in Language Models
**Yao et al., ICLR 2023**

Interleaves reasoning with actions for tool use.

- **Key innovations**: Thought-action-observation loops
- **Impact**: Foundation for tool-using agents
- **Link**: [arXiv:2210.03629](https://arxiv.org/abs/2210.03629)
- **Status**: 📖 Essential

---

### Toolformer: Language Models Can Teach Themselves to Use Tools
**Schick et al., Meta 2023**

LLMs learning to use external tools autonomously.

- **Key innovations**: Self-supervised tool learning
- **Impact**: Showed LLMs can learn tool use
- **Link**: [arXiv:2302.04761](https://arxiv.org/abs/2302.04761)
- **Status**: 📖 Essential

---

### Reflexion: Language Agents with Verbal Reinforcement Learning
**Shinn et al., NeurIPS 2023**

Agents that learn from verbal self-reflection.

- **Key innovations**: Verbal reinforcement, episodic memory
- **Impact**: Self-improving agents
- **Link**: [arXiv:2303.11366](https://arxiv.org/abs/2303.11366)
- **Status**: 🔧 Hands-on

---

## Multi-Agent Systems

### Large Language Model based Multi-Agents: A Survey of Progress and Challenges
**Guo et al., IJCAI 2024**

Comprehensive survey of LLM-based multi-agent systems.

- **Key value**: Taxonomy, challenges, future directions
- **Link**: [arXiv:2402.01680](https://arxiv.org/abs/2402.01680)
- **Status**: 📖 Essential

---

### LLM Multi-Agent Systems: Challenges and Open Problems
**Han et al., 2024**

Analysis of challenges in multi-agent collaboration.

- **Key topics**: Communication, coordination, emergence
- **Link**: [arXiv:2402.03578](https://arxiv.org/abs/2402.03578)
- **Status**: 📖 Essential

---

### AutoGen: Enabling Next-Gen LLM Applications via Multi-Agent Conversation
**Wu et al., Microsoft 2023**

Framework for multi-agent conversations.

- **Key innovations**: Conversable agents, human-in-the-loop
- **Impact**: Popular multi-agent framework
- **Link**: [arXiv:2308.08155](https://arxiv.org/abs/2308.08155)
- **Status**: 🔧 Hands-on

---

### CAMEL: Communicative Agents for "Mind" Exploration
**Li et al., NeurIPS 2023**

Role-playing framework for agent collaboration.

- **Key innovations**: Inception prompting, role assignment
- **Link**: [arXiv:2303.17760](https://arxiv.org/abs/2303.17760)
- **Status**: 🔧 Hands-on
